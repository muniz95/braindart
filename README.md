# BrainDart

A modern [Brainfuck](https://en.wikipedia.org/wiki/Brainfuck) interpreter built with Dart.

## Features

- Interactive code editor with syntax highlighting
- Visual execution control (play, pause, resume, stop)
- Adjustable execution speed
- Live memory tape visualization
- Fully responsive design for mobile and desktop
- Dark mode support

## Development

This project is built with Dart. To run it locally:

1. Install the Dart SDK
2. Clone this repository
3. Run `dart pub get` to install dependencies
4. Run `dart pub global run webdev serve` to start a development server

## Deployment

To deploy to GitHub Pages:

```bash
npm run deploy
```
